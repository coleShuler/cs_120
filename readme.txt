
The Goal in this project is to see if I can make a rhythm game for the song called "Runaway" by an artist named Potsu. This song is fast, rhythmically hard, and can bring a challenge to the programing with a 109 BPM. This game I am hoping challenges me with my organizational skills, and coding skills as a whole.


To play the game the player will not need a controller, simply just a keyboard with a spacebar. The game will have instructions on how to play when started up, so the player can figure out the controls without any issue.


Some things I used in my game were the use of inporting simpleGE and pygame, heavy using classes, key inputs, and as well as setting up a space for the game to exist in. This game has some stutter issues due to some limitations, however the game speed compensates for most of the speed issues.


Sources I used were the Free domain background, key textures, and rhythm objects used in the game. The Objects were found using openclipart.org and the background in adobes free library of assets. The song was made by Potsu and can be found on all music platforms.


I think it would be amazing to try and fix the structure of the code to fix the buttons and beats so 4 buttons can be used. I would also like to implement a reset system to make the game more replay able. I would also like to redesign the way the beats fall. The way the beats fall is predictable and easy to determine. If I could make a system that would be easier to set up and possibly even easier to customize, I think it would have helped with designing the beat system in the game. I think the limitations I had when making the game started to lead me away from the game design document, however I tried to keep close to make sure I wasn't moving to far way from my main idea.
